# North Georgia Holiday Events
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
User specified React, TypeScript, Vite, Tailwind, FastAPI, uv, SQLite, Leaflet/OpenStreetMap, and Docker Compose on Synology DS1821+.
## Users
Jason and LAN visitors finding holiday events; one administrator maintains the calendar.
## Product Purpose
Find Christmas events and concerts across North Georgia using listings, a map, and a calendar. Support future years without code changes.
## Operating Context
Deployed on the NAS for LAN access; preparing anonymous read-only viewing by friends with a browser link. No visitor accounts required. Public gateway/hosting remains to be discussed. Approved-source discovery and change checks run on a schedule; only an administrator can review and publish them. No paid discovery API or hosted AI required.
## Capabilities and Constraints
Public read-only views; one protected administrator. Private source-review queue with approval history, cancellation/postponement and concurrent-edit protection. Public HTTPS mode requires explicit host/origin and stronger credentials. Import/export CSV and JSON. Preserve unverified entries with public labels. Never invent coordinates or uncertain times and prices. Cache geocoding permanently; provide manual coordinate correction. Eastern Time.
## Brand Commitments
North Georgia Holiday Events. Jason originally approved an understated holiday guide. On November 11, 2026, he requested a more colorful Christmas theme using red, green, silver and gold, plus an identifiable app/browser icon. Keep the event list beside the map.
## Evidence on Hand
The pasted requirements supply the initial November/December 2026 event list. Official sources must support confirmation. No supplied imagery or brand assets.
## Product Principles
- Make dates and uncertainty clear.
- Keep application data local and portable.
- Make future seasons editable rather than hard-coded.
